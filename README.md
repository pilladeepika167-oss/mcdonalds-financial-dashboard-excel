# 📊 McDonald's Financial Performance Dashboard (Excel)

## 📌 Project Overview

This project presents an interactive Financial Performance Dashboard for McDonald's using Microsoft Excel. The dashboard analyzes the company's financial performance from 2002 to 2022 through data visualization and key financial metrics.

The project demonstrates Excel-based data analysis, financial reporting, and dashboard design using PivotTables, PivotCharts, and KPI cards.

---

## 🎯 Project Objectives

- Analyze McDonald's financial performance over 21 years (2002–2022).
- Visualize key financial metrics using interactive charts.
- Compare financial trends and business performance.
- Develop a professional Excel dashboard for financial analysis.

## 📂 Dataset

The dataset contains McDonald's financial information from **2002 to 2022**, including:

- Market Capitalization
- Revenue
- Earnings
- Operating Margin
- Earnings Per Share (EPS)
- Dividend
- Cash on Hand
- Net Assets
- Total Assets
- Total Debt
- Total Liabilities

---

## 📌 Key Insights

- Revenue remained relatively stable over the analysis period.
- Earnings showed long-term growth despite periodic fluctuations.
- Market capitalization increased significantly over time.
- Operating margin improved compared to earlier years.
- Dividend per share increased consistently from 2002 to 2022.
- Total assets and liabilities changed alongside business expansion.
- EPS demonstrated overall positive growth.
- Cash on hand varied across different financial years.
